# Security Policy

## Supported versions

Security fixes are applied to the latest release on the `main` branch when feasible.

## Reporting a vulnerability

Please **do not** open a public issue for sensitive security reports.

Prefer one of:

1. [GitHub Security Advisories](https://github.com/luszechai/HSR-Story-Auto-Skipper/security/advisories/new) (private), or
2. Contact the maintainer [@luszechai](https://github.com/luszechai) privately.

Include steps to reproduce, impact, and (if possible) a suggested fix.

We will acknowledge the report when possible and work on a fix or mitigation.
