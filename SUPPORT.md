# Support

## How to get help

1. **Download / run the app** — use the latest [Release](https://github.com/luszechai/HSR-Story-Auto-Skipper/releases/latest). Extract the full zip and run `HSR Auto Skip.exe` (admin UAC is expected).
2. **Read the README** — setup, features, and troubleshooting: [README.md](README.md).
3. **Open an Issue** — bugs and feature requests: [Issues](https://github.com/luszechai/HSR-Story-Auto-Skipper/issues).

Please include: Windows version, game windowed resolution, what you expected vs what happened, and screenshots if useful.

## Out of scope

- Requests that involve bypassing game anti-cheat or encouraging ToS violations beyond personal tooling discussion.
- Support for modified / cracked game clients.
